## 🌟 Key Features

* **Editor Memory Optimization**: Allocates execution memory specifically during active Elementor editor sessions.
* **Asset Deferral**: Defers non-essential editor scripts until canvas initialization completes.
* **Heartbeat Throttling**: Reduces background Heartbeat API frequency while editing to save CPU resources.
* **Zero Frontend Impact**: Does not alter frontend CSS/JS delivery or site styling.
